# 🧠 Cogniview — AI SaaS Dashboard  

**Enterprise-grade AI-powered SaaS platform for real-time analytics, predictive insights, and intelligent team collaboration.**  
Built with a modern full-stack architecture using **Next.js, Node.js, PostgreSQL, Docker, TailwindCSS, OpenAI, and LangChain**.

## 🚀 Overview  

Cogniview is an **AI-powered SaaS Dashboard** designed for enterprises that need **real-time data analytics**, **multi-tenant separation**, and **AI-driven business insights**.  
It brings together **authentication**, **billing**, **admin analytics**, and **predictive intelligence** into a unified dashboard experience.  


![Screenshot](/client/docs/screenshot.png)

## ⚙️ Features  

- 🔐 **Authentication & Role-Based Access Control (RBAC)**  
- 💳 **Subscription Billing (Stripe Integration)**  
- 🏢 **Multi-Tenant Architecture (MongoDb)**  
- 📈 **Admin Analytics Dashboard**  
- 🤖 **AI Insights & Anomaly Detection (OpenAI + LangChain)**  
- 🧠 **Chat Assistant for Data Queries**  
- ⚡ **Real-Time Analytics & Alerts**  
- ☁️ **Scalable Deployments with Vercel & Render**  

## 🧰 Tech Stack  

| Layer | Technologies |
|--------|---------------|
| **Frontend** | React.js, TailwindCSS |
| **Backend** | Node.js, Express.js |
| **Database** | Mongo DB (Multi-tenant ) |
| **AI/ML** | OpenAI API, LangChain |
| **Payments** | Stripe |
| **Containerization & CI/CD** | Docker, GitHub Actions |
| **Hosting** | Vercel (Frontend), Render (Backend) |
